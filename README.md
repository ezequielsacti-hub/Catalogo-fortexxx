# FORTEX SRL — Catálogo online

Catálogo estático de productos con buscador, filtros y carrito interactivo.

## Publicar con GitHub Pages

1. Subí **todos los archivos y la carpeta `assets`** de este paquete a la raíz del repositorio.
2. En GitHub, abrí **Settings → Pages**.
3. En **Build and deployment**, elegí **Deploy from a branch**.
4. Elegí la rama `main` y la carpeta `/ (root)`, y guardá.
5. Esperá a que GitHub Pages publique el sitio.

## Importante

- Los precios son de ejemplo: reemplazalos por los valores reales.
- El carrito calcula el subtotal, pero no procesa pagos reales.
- No cambies de ubicación los archivos dentro de `assets`, porque ahí están las imágenes.
